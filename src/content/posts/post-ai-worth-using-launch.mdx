There's a lot of hype in AI, and very little of it holds up in real work.

So Sam Odio and I started **[AI Worth Using](https://aiworthusing.com/)**, a new show where the top engineers in AI screen-share the setup they actually use every day, then install it live on my machine. No slideware. No hand-waving. If a tool can't survive a live install and a real task, it isn't AI worth using.

The show goes live **today, Tuesday, September 1**, with two episodes out on day one:

**[Episode 1: Jesse Vincent on Superpowers](https://www.youtube.com/watch?v=QeNVb-UfV3s).** Open-source veteran Jesse Vincent shows me Superpowers, currently the #1 developer plugin for Claude Code, and I accept his challenge to use it to rewrite GitHub.

**[Episode 2: Wes McKinney on Roborev](https://youtu.be/SyXRrdUvkbYE).** Humans get sick of doing code reviews, but AI never tires. The creator of Pandas shows me Roborev, his latest project for keeping agents busy reviewing code continuously in the background.
